# 音准镜（Voice Pro）产品文档

## 定位
帮唱歌的人找出"哪里唱不准"。用户导入一首歌，跟着唱，软件实时显示自己的音高和原唱旋律的对比，唱完给出逐句报告：哪句偏高/偏低、偏多少音分。

## 目标平台与技术路线
- 一套 Web 代码（React + Vite + TS），PWA 可直接在浏览器用。
- 移动端：Capacitor 打包 iOS / Android；桌面端：Tauri 打包 Windows / macOS / Linux。
- 上架：App Store、Google Play、Microsoft Store、Mac App Store（后期）。

## 核心流程（MVP）
1. 导入歌曲（mp3/m4a/wav/flac）→ 本地提取人声旋律（不上传服务器，隐私友好）。
2. 练唱：播放伴奏/原曲，实时画两条音高线（原唱旋律 vs 我的声音），偏差着色。
3. 报告：按乐句列出偏差，可点击回放该句、只练这一句。

## 音频来源
- 默认：麦克风（全平台）。
- 桌面浏览器：可捕获标签页/系统声音（getDisplayMedia），用于"别的软件在放歌"时分析该声音的音高。
- 手机系统不允许 App 读取其他 App 的播放声音；手机上"别的 App 放歌"场景只能靠麦克风收音，需要提示戴耳机，否则外放会串音。

## 体验原则
- 打开即用，3 步内开始唱。
- 实时延迟目标 < 50ms 视觉反馈。
- 默认戴耳机提示；外放时做回声/串音提示。
- 偏差容忍度可调（默认 ±50 音分算准）。

## 路线图
- v0.1 原型：麦克风实时音高 + 导入歌曲提取旋律 + 对比视图 + 报告（Web）。
- v0.2 根据体验反馈打磨；移调（升降 key）、八度自动对齐、乐句循环练习。
- v0.3 人声分离模型（ONNX）提高旋律提取准确度；歌曲库本地保存。
- v0.4 Capacitor/Tauri 打包，各商店上架材料。

### 2026-11-06 v0.5 延迟与手机分离
- 延迟校准已加：外放 click（7 次取中位数）和戴耳机跟拍（10 拍，结果含人的反应时间）。结果按输出设备 label、拿不到 label 时按「外放/有线/蓝牙」分别保存，练唱时自动套用；未校准只在准备页给一句轻提示，不拦着开始。手动补偿仍可覆盖。
- Android WebView 结论：Capacitor 本地资源服务没有 COOP/COEP 配置入口，`crossOriginIsolated` 通常为 false，onnxruntime-web 只能单线程 WASM；AndroidX WebKit 1.18 的跨源隔离白名单还要求 `Document-Isolation-Policy` 响应头，Capacitor 当前给不了。WebGPU 取决于系统 WebView（Chrome 121+/Android 12+ 在浏览器里可用，WebView 未确认），代码里保留运行时检测与 WASM 回退，没有可靠的 native 开关可配。
- 快速分离模式：不依赖 SharedArrayBuffer，0.5 s 重叠 + 多 Worker 各建 ORT 会话并行分段；默认手机快速、电脑标准，设置可切。22 首真实歌 OA 79.9→79.8（−0.1），桌面模拟手机单线程的 24 s 音频端到端 62.4 s→16.2 s；手机预计约 1.8–2×，待真机验证。
- 「先给不分离的粗略旋律」不采用：EVAL 里直接提取 OA 38.2%，中置声道也只有 36.9%，都不可用。导入等待时改为引导去音准仪/练声小课，后台继续分析。
