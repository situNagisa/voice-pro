## 一句话说明

音准镜是一款本地练唱工具。**我们不收集、不上传、不共享你的任何个人信息或音频。** 麦克风采集的声音只在你自己的设备上实时分析；练习录音和音高数据只保存在本机。

## 1. 我们收集哪些信息

本应用**不收集任何个人信息**，具体包括：

- 不要求注册账号，不收集姓名、手机号、邮箱、身份证号等身份信息；
- 不收集设备标识符（IMEI、Android ID、广告 ID 等）、位置、通讯录、相册或剪贴板内容；
- 不接入任何统计分析、广告、推送或第三方追踪 SDK；
- 不向任何服务器上传音频、录音、音高数据或练习记录。

## 2. 麦克风与音频处理

- **用途**：练唱和音准仪需要使用麦克风，实时计算你的音高，并与参考旋律对比。
- **处理方式**：音频在设备本地由 Web Audio / WASM / ONNX 模型处理，音高检测、人声分离和评分均在本机完成。
- **是否上传**：否。本应用没有音频上传功能，也没有用于接收音频的服务器。
- **是否保存**：只有当你开始一次练习时，应用才会在本机保存这次练习的录音（用于回放“刚才唱的”）以及对应的音高轨迹。你可以在“记录”中删除任意一条记录。
- **声纹**：我们不对录音进行声纹识别，不建立声纹模板，不将录音用于身份识别。
- **权限**：麦克风权限由操作系统管理。你可以随时在系统设置中关闭；关闭后仍可浏览界面和查看历史记录，但无法进行实时练唱。

## 3. 本地存储的内容

| 存储位置 | 内容 | 用途 |
| --- | --- | --- |
| IndexedDB | 练习录音、音高轨迹、逐句评分、歌曲名称与练习时间 | 在“记录”中回看和回放 |
| localStorage | 判定阈值、音量、界面设置、最近使用的歌曲名称 | 记住你的偏好 |

- 导入的歌曲文件只被读入内存进行分析，**不会保存原曲音频**，也不会上传；重新打开应用后需要重新选择文件。
- 我们不使用云同步。Android 版本已关闭系统自动备份（`allowBackup=false`），录音不会进入系统云备份或换机迁移。
- 删除方式：在“记录”中删除单条记录；或在系统设置中清除应用数据 / 清除浏览器站点数据；卸载应用会删除全部本地数据。

## 4. 网络与第三方

- 本应用的核心功能离线可用。音高检测、人声分离模型、示例曲均随应用一起发布，不依赖在线服务。
- 网页版通过 HTTPS 加载静态页面。托管服务商可能像所有网站一样记录基础访问日志（IP 地址、浏览器类型、访问时间），仅用于安全与运维，本应用不读取、不分析这些日志，也不在页面中嵌入统计或广告脚本。
- 本应用使用的开源组件（如 ONNX Runtime Web、pitchy）仅在本机运行，不包含数据上报功能。

## 5. 账号、广告与追踪

- 无账号体系，无登录、无云端用户资料。
- 无广告、无个性化推荐、无行为追踪、无跨应用追踪。
- 不向任何第三方出售、出租或共享个人信息。

## 6. 系统权限说明

| 平台 | 权限 | 说明 |
| --- | --- | --- |
| Android | `RECORD_AUDIO` | 练唱时采集音高 |
| Android | `MODIFY_AUDIO_SETTINGS` | 播放与采集音频时的音量/路由设置 |
| Android | `INTERNET` | 仅用于 WebView 加载本地打包的页面资源 |
| iOS / macOS | 麦克风 | 练唱时采集音高，系统会弹出授权提示 |
| Windows | 麦克风 | 由 Windows 隐私设置与 WebView2 管理 |

本应用不申请相机、定位、通讯录、短信、通话记录、存储读写等与功能无关的权限。

## 7. 儿童隐私

本应用不是面向儿童设计的产品，不主动面向 14 周岁以下儿童提供服务。由于本应用不收集任何个人信息、没有账号和网络上传，儿童使用时也不会向我们传输数据。如果监护人对本机保存的练习记录有疑问，可以通过下方联系方式联系我们，或直接在应用内/系统设置中删除数据。

## 8. 你的权利

由于数据只保存在你的设备上，你可以直接：

- **查看**：在“记录”中查看练习记录；
- **删除**：删除单条记录，或清除应用数据 / 站点数据；
- **撤回授权**：在系统设置中关闭麦克风权限；
- **导出/迁移**：本应用当前不提供云端导出。

如你对个人信息处理有疑问、投诉或需要协助，请通过下方联系方式联系我们。我们会在 15 个工作日内答复。

## 9. 数据安全

- 音频与练习记录存储于应用私有目录，受操作系统沙箱保护。
- 应用不建立远程连接传输音频，降低泄露风险。
- 请注意：任何设备都可能被他人物理接触。建议为设备设置锁屏密码，并在共用设备上及时删除练习记录。

## 10. 政策更新

如果本应用未来增加云同步、账号、分析或其它会改变数据处理方式的功能，我们会在上线前更新本政策，并在应用内显著提示。继续使用即表示你接受更新后的政策；如不同意，你可以停止使用并删除本地数据。
