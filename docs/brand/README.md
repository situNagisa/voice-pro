# 音准镜品牌素材

## 图形

- 圆环 + 四向准星：取“镜”和“准星”的意象，对应产品名“音准镜”。
- 五根声波柱：中间的柱最高，两侧递减，表示实时音高曲线与偏差。
- 配色取自 `src/index.css` 的 CSS 变量：背景 `#090a0e` / `#12141b`，强调色 `#8f7dff`，准音绿 `#2ec4a0`。

| 用途 | 颜色 |
| --- | --- |
| 背景渐变 | `#17142a` → `#0b0c14` → `#07080c` |
| 圆环渐变 | `#b3a6ff` → `#8f7dff` → `#2ec4a0` |
| 声波柱渐变 | `#c6bdff` → `#9a8bff` → `#6d5cf0` |
| 准星刻度 | `#8f7dff`（80% 不透明） |

## 文件

| 文件 | 说明 |
| --- | --- |
| `icon.svg` | 主图标，512 圆角方形 |
| `icon-round.svg` | 圆形版本 |
| `icon-maskable.svg` | PWA maskable，满幅背景 |
| `icon-foreground.svg` | Android 自适应图标前景，内容缩到安全区 |
| `icon-background.svg` | Android 自适应图标背景（深色渐变） |
| `icon-1024.png` | 1024×1024 预览 |
| `icon-round-512.png` | 圆形预览 |

## 使用规范

- 图标最低使用尺寸 24px；小于 32px 时优先使用单色/简化版本，不要在深色图标上再叠加阴影。
- 安全区：Android 自适应图标与 PWA maskable 的内容都在中心 66% 圆内，四周留白不要裁掉。
- 不要在圆环内再加文字；应用名只在启动屏和商店素材中使用。
- 修改母版后执行 `npm run icons` 重新生成所有平台资源，不要单独改 `public/` 或 `android/` 里的 PNG。
- 生成依赖 `rsvg-convert`（Arch：`librsvg`）与文泉驿微米黑（启动屏中文）。
